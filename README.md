# Learn JavaScript

This repository contains examples and explanations to help beginners learn JavaScript from scratch. The topics are arranged in a recommended learning order, starting with core fundamentals and progressing to advanced asynchronous programming concepts.

## Prerequisites

* Basic understanding of HTML and CSS
* Visual Studio Code (VS Code)
* Modern web browser (Chrome, Firefox, Edge)
